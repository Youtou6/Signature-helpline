Sauvegarde de la configuration

Les catégories, textes et réglages vivent sur le disque du serveur, qui est réinitialisé à chaque redéploiement. Exporte une sauvegarde avant de pousser du code, et réimporte-la juste après.

Fermeture automatique

Si le staff a déjà répondu au moins une fois, et que le ticket est inactif pendant la durée ci-dessous, l'utilisateur reçoit un avertissement en MP. S'il ne répond toujours pas après le délai de grâce, le ticket est fermé automatiquement.

Catégories

Chaque catégorie est une option de support proposée à l'utilisateur. Assignez des rôles pour que seul le bon staff voie ces tickets. Les questions sont posées dans l'ordre ci-dessous ; une question peut être conditionnée à la réponse d'une question à choix précédente (ex : "Service custom" → "Quel service ?" → questions différentes selon la réponse).

Textes du bot

Tous les messages envoyés par le bot pendant le parcours d'un ticket. Le message de bienvenue est affiché avant le choix de langue (donc en un seul texte, généralement bilingue).

Utilisateurs bannis

Un utilisateur banni ne peut plus ouvrir de nouveau ticket (il reçoit un message l'informant que ce n'est pas possible). Pour trouver un ID Discord : mode développeur activé, clic droit sur le membre > Copier l'identifiant.
